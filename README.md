- **💎 Atmospheric "Luminous Nexus" Theme:**
  - **Ceylon Bio-Alabaster Canvas (`#EDF6F2`)** creating 3D depth for floating white frosted glass cards.
  - **Deep Obsidian Sapphire (`#071326`)** high-contrast typography.

  - **Ceylon Flora Emerald (`#059669`) & Neon Mint (`#10E599`)** symbolizing organic root health and NDVI vegetative vigor.

- **💊 Morphic Capsule Segment Navbar (`MorphicNavbar`):**
  - Dynamic segment capsule navigation with spring elevation, active route transitions, and responsive mobile drawer.

- **🔍 Spotlight Command Search Palette (`CommandSearch.tsx`):**

  - Interactive grid covering Commercial Coconut Estates, Dutch Hydroponics, Highland Ceylon Tea, Vertical Farms, and Bulk 40ft Container Fleet Logistics.

- **📚 Watermelon UI `Blog-2` Publications Hub (`Blog2.tsx`):**
  - Multi-gradient rounded 4xl glass cards for agronomy whitepapers, LoRaWAN firmware notes, and blockchain export passports.

- **🗺️ Interactive Spring-Animated Map Modal (`ViewOnMap.tsx`):**
  - Expanding live Google Map pop-up for the Colombo World Trade Center headquarters.

- **🔗 Kokonut UI Expandable Social Share Pill (`SocialShareButton.tsx`):**

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18.18.0 or higher
- `npm`, `pnpm`, or `yarn`

### 1. Installation
Clone the repository and install dependencies:

```bash
git clone https://github.com/<your-username>/natle-agritech-platform.git
cd natle-agritech-platform
npm install
```

### 2. Development Server

#### Option A: Windows One-Click Runner
Simply double-click the included `start.bat` file in the project root. It will verify dependencies, start the Turbopack server, and open `http://localhost:3000` automatically in your default browser.

#### Option B: Standard Terminal Command
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build & Verification
```bash
npm run build
npm run start
```

To run type checking across all routes:
```bash
npx tsc --noEmit
```
